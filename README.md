legal-ai-court
A multi-agent legal AI architecture prototype (Prosecutor, Defender, Judge) featuring Human-in-the-loop fallback.

🚀 Roadmap (Development Plan)
☑ v1.0 (Current): Multi-agent asynchronous orchestration via APIs (DeepSeek, Kimi, GLM) + Real-time human lawyer intervention.
□ v2.0 (Next): Integration of RAG (Retrieval-Augmented Generation) to lock down factual accuracy and legal provisions.
□ v3.0: Local deployment support (Ollama + open-source models) to ensure data privacy and bypass API restrictions.
（翻译一下：第一版是异步多智能体+人类兜底；第二版才是接入RAG锁死事实；第三版搞本地化部署。）
